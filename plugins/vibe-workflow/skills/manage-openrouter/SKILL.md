# Manage OpenRouter Integration

Read the [local procedure](references/procedure.md) for the requested control.
Activation stays separate from Onboard my Project, which may only offer it.
Worker consent covers scoped editing and registered checks; the current runner is
read-only and runs neither.

Default to native execution; enablement is the only approval for autonomous use.
Save enablement only for the supported enrolled checkout. Report saved enablement,
local configuration and observed execution separately. Preserve native model
choices, authentication and customizations.

OpenRouter owns spending limits. Never store keys in workflow settings, treat an
account connection as consent, or infer Project-wide membership. Disable blocks
new managed admissions; already-admitted work can settle and receive native
verification. It neither revokes account access nor stops direct MCP calls.
