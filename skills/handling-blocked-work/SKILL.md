# Handling blocked work

For workflow-enrolled tasks, use the accepted package and task policy pins. Apply the [policy index](../../policies/00-index.md); read applicable contracts in full unless already current in context.

Determine what stopped: an action, run, phase, or task. Check the original grant, who set the limit, and what it covers.

Apply:
- [Scope](../../policies/01-project-scope.md): authority and reserved decisions.
- [Planning](../../policies/02-task-planning.md): limits and dependencies.
- [Lifecycle](../../policies/07-context-and-handoff.md): remaining actions and continuation.
- [Maintenance](../../policies/09-workflow-maintenance.md): qualification or improvement trials.

Use existing task context to apply the required disposition to all remaining actions. Skill loading and follow-up remain within current authority and budgets.
