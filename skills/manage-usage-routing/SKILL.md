# Manage API Usage

Worker choices need only [their reference](references/worker-choices.md).
Read [management](references/procedure.md) for setup, activation, status,
previews and [managed projects](references/procedure.md#managed-projects). Load [Keychain setup](references/keychain-setup.md) for new
connections, [delegation](references/delegation.md) for eligible proposals or
native handoff, and [foreground canary](references/first-canary.md) only for
an expressly selected test.

Default Off. Reuse compatible setup or connect Keychain, then activate this
checkout. Activation is the only approval: the agent then routes eligible tasks
itself within the saved scope, funding and caps. Trusted admission checks
scope, funding, price and independent review before transmission.

Keep the coordinator and existing provider choices. Use approved existing
credits, retain uncertain costs and warn about possible provider-side funding
spill. Never purchase credits, change billing or switch to a paid fallback.
