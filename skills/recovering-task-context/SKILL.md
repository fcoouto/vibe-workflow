# Recovering task context

For workflow-enrolled work, resolve the accepted package and task policy pins from governing instructions and existing records; never substitute current defaults.

Apply the [policy index](../../policies/00-index.md); read applicable contracts in full unless already current in context.

Identify the missing basis for the next decision:
- [Scope](../../policies/01-project-scope.md): enrollment, authority and policy pins.
- [Planning](../../policies/02-task-planning.md): accepted outcome, remaining limits and dependencies.
- [Lifecycle](../../policies/07-context-and-handoff.md): canonical records, actual state and ownership.

Missing pointers or authority block only dependent actions. Preserve pauses, ownership and remaining limits; recovery does not authorize continuation.
