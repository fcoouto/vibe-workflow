# Project layout

Read [the procedure](references/procedure.md) from this skill's bundled directory
before you create, move or rename a file or folder, and before any restructure.
[The example layouts](references/layouts.md) hold trees to consult when nothing
else in the project decides. Follow the project's own layout;
move nothing the user did not ask for directly or approve in a plan.
