# Efficient template assistance

Approved in chat on 11 November 2026: selective loading plus deterministic preparation and checks, with optional thin hooks after the checker proves useful. The coordinator implements inline to avoid repeated worker context; one independent final review remains required.

## Intent and approaches

Improve useful template output while reducing repeated reads, generated boilerplate and repair turns. Keep semantic decisions with the agent. Prose-only changes leave mechanical errors unresolved; a universal schema/generator duplicates existing records. The approved middle path reuses the prepared reader, canonical document mapping, evidence and assignment owners.

## Small implementation boundary

Provide a standard-library, read-only command with two operations. `prepare` accepts explicitly selected template paths and required context paths in the actual consumer checkout, reports observed time and content hashes, and delivers selected templates through the existing revision-bound reader. `check` examines only explicit output documents, optionally compares their original lines against a protected before-directory, checks required context digests, local Markdown links and known template residue, and returns compact findings. Original prose and existing commands remain authoritative. No generated parallel document schema, database, enrollment, Git requirement, network, command execution, model call or automatic edit.

The CLI is the first callable trigger at document-batch completion and before assignment launch. Expose a pure, bounded notice formatter for future hook callers: silent success, short findings, content-bound duplicate suppression supplied by the caller. Do not install or register native hooks until actual client behavior is tested; a replayed hook fixture is not live qualification. Existing permissions and managed controls remain unchanged.

Only inputs explicitly named by the caller are inspected. Refuse traversal, symlinks and nonregular selected files; bound bytes and file counts. Link checks never fetch external URLs. A protected baseline is caller-owned evidence, not permission or an authenticated fact. Preservation checks cover original nonblank lines and multiplicity, not semantic equivalence. Exact source placeholders and recognizable newly added author directions are findings, never automatic deletions. Unsupported Markdown forms retain explicit coverage limits.

## Proof and rollout

Test missing consumer context, stale hashes, valid combined documents, preserved author-like originals, actual leftover placeholders, broken destination-relative links, path escapes, bounded reads and silent/deduplicated notices. Replay retained synthetic failures with independent positive controls. Keep historical evidence immutable. Compare baseline/candidate requirements identically and distinguish functional checks from semantic acceptance. Live model trials need a fresh explicit numeric budget because earlier trials are closed. Native hook installation follows checker usefulness and client qualification; this implementation does not silently enable it.

Measure actual input/cache/output tokens and requests per model in a later authorized pilot; byte reduction is not token or billing savings. Package export cleanup is independent and excluded from this implementation. Completion means verified code and instruction paths, independent review, and published changes with live-pilot/hook limits explicit.
